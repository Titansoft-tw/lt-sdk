# lt-telemetry-android (#3)

OTLP/HTTP JSON log encoding and delivery for lt-observability. Package `com.tswork.lt.telemetry`, minSdk 26, depends
on `lt-device-info-android` (exposed as `api`). No OkHttp or coroutines: `HttpURLConnection` on one daemon thread.

```kotlin
val telemetry = LtTelemetry(TelemetryConfig(
    logsUrl = BuildConfig.TELEMETRY_URL,                  // full URL, e.g. https://otel.example/v1/logs; blank = off
    headers = { mapOf("Authorization" to "Bearer $token") },
    requireHttps = !BuildConfig.DEBUG,
    serviceName = "lt-call-demo",
    device = deviceInfo.staticDevice,
    storageDir = context.noBackupFilesDir,
    log = { Log.i("App", it) },                           // only on delivered <-> failing changes, never the URL
))
val leg = TelemetryLeg(callId, channel, user, engine = "agora", sdkVersion = "agora-4.7.0")
val ctx = TelemetryContext(deviceInfo.network(), deviceInfo.audioRoute(), deviceInfo.deviceState())
telemetry.send(listOf(Telemetry.qualitySecond(leg, metrics, System.currentTimeMillis(), ctx)))
telemetry.writeCallMarker(CallMarker(...).encode())       // null clears it; readCallMarker() at launch
```

| File | What |
|---|---|
| `Telemetry.kt` | `TelemetryRecord`, `TelemetryLeg`, `TelemetryContext`, `AudioMetrics`, `LabTag`, record builders, `logsJson`, `scrub` |
| `AppTelemetry.kt` | `Severity`, `ErrorDomain`, `AppError`, `ApiErrors`, `SignalingErrors`, `MicEvent`, `DeviceWatch`, `AppErrorTally`, `CallMarker` |
| `TelemetryStore.kt` | On-disk queue: every record is appended to a segment file before `send` returns (survives a crash or a killed process); lanes CRITICAL (`app_error`, `abnormal_exit`) → EVENT → BULK (`quality_second`) set send order and, over 5 MB, eviction order (BULK first); 7-day max age; `log.record.uid` per record; dropped counts by reason |
| `PushTelemetry.kt` | `PushErrors`, `Fgs` |
| `CallSetup.kt` | `SetupStage`, `AgoraCodes` |
| `LtTelemetry.kt` | `TelemetryConfig`, transport: sends from `TelemetryStore` (one segment of at most 200 records per POST, CRITICAL first, `observedTimeUnixNano` = send time); 0/408/429/5xx retried with backoff 10 s doubling to 5 min ±20% or after `Retry-After` (capped at 1 h), other 4xx dropped; what is left goes out at the next launch; `flush()` (network back, app to background) cuts a client backoff short; a `sdk_event label=telemetry reason=dropped` with `dropped_<reason>` counts once delivery works; imports the old `telemetry-durable.txt` once; call marker file; `writeHeld` / `takeHeld` (records the app holds until the call_id is final, on disk); `drain(timeoutMs)` (blocking, for a WorkManager job; `onBacklog` says when one is needed); startup-crash wait (a process that died within 5 s of starting makes the next constructor wait up to `startupCrashWaitMs` for the first send); remote config: `settings`, `refreshConfig(minIntervalMs)` (GET `<base>/config/telemetry.json` with ETag, cached on disk, `config_version` on every record, kill switch, `drop_labels`, retry and queue limits) |
| `RemoteTelemetryConfig.kt` | `TelemetrySettings`, `ConfigTarget`, `RemoteTelemetryConfig.parse` (schema 1: clamps, ordered rules on platform / build / version range, local rollout bucket), `QualitySampling` (per-call `quality_every_s`, `call_sample_percent`, `batch_records`), a dependency-free JSON reader |
| `lab/LabTelemetry.kt` | `net_probe`, `path_trace`, `case_result`, `PathTrace.compact` (running the trace stays in the app) |
| `Contract.kt` | Generated by `lt-telemetry-contract/generate.js`; do not edit |

Extracted from lt-call-demo `rtc/Telemetry.kt`, `rtc/AppTelemetry.kt`, `rtc/PushTelemetry.kt`, `rtc/CallSetup.kt` and
the transport in `CallEnvironment.kt` (`AndroidCallEnvironment`). Left in the app: `Telemetry.connectivity()` (needs the
app's `Provider`), `CallIdAgreement` / `CallIdMessage`, `PathTrace.run`. Differences: `logsJson` takes the
`serviceName`; there is no device-wide `sdk_version`, so a record without an engine (`app_start`) no longer sends a
blank one. Not yet (plan §6): `CallTelemetry`, `setup_id`, clock offset, `onRecord`, `launched()`.
