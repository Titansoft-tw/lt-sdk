# lt-error-guard-android (#7)

Decides which handled error events reach the crash reporter (rules: `lt-error-guard-spec`). Package
`com.tswork.lt.errorguard`, minSdk 26, no dependencies (rules are parsed with the platform's `org.json`). Crash-reporter
neutral: `lt-error-guard-sentry-android` (#8) plugs it into Sentry; another reporter needs only a `GuardEvent` mapping.

```kotlin
val guard = ErrorGuard(
    rules = GuardRules.DEFAULT,                      // or GuardRules.parse(json): throws IllegalArgumentException
    sink = { first -> telemetry.send(listOf(Telemetry.appError(/* ... */))) }, // optional, see below
)
guard.decide(GuardEvent(exceptionTypes = listOf("java.net.UnknownHostException"))) // Decision(keep = true, rule = "net-io")
val totals = guard.endSession()                      // counts above 1; also starts a new session
```

Thread-safe; the sink is called outside the lock and may call back into the guard. A session is whatever the app
chooses (the process, or one call): call `endSession()` at its end.

**Back to lt-observability** (no contract change): send the sink's `Suppressed` and every entry of `endSession()` as
an `app_error` with `error_domain = domain`, `error_code = code`, `count = count`, severity `WARN`. The first arrives
with count 1 and the total later, which `v_app_error` already reads as max per code.

**Remote rules** (`lt-error-guard-spec` README "Remote rules"): a signed file replaces the rules while the app runs.

```kotlin
val loader = GuardRulesLoader(guard, "https://cdn.example.com/guard/android.json", BuildConfig.GUARD_RULES_PUBLIC_KEY,
    cacheFile = File(context.noBackupFilesDir, "guard-rules.json"),
    onApplied = { version -> Sentry.setTag("guard_rules_version", "$version") })
loader.applyCached()                    // at start, before the crash reporter sends anything
val periodic = loader.startPeriodic()   // refresh now and every 6 h on a daemon thread; periodic.close() stops it
```

`refresh()` is blocking and returns `RulesUpdate.Applied` / `Unchanged` / `Rejected` / `Failed`; the default fetch
needs https, times out after 10 s and refuses bodies over 256 KB. `guard.updateRules(rules)` is there for apps that
load rules their own way.

| File | What |
|---|---|
| `GuardRulesLoader.kt` | `GuardRulesLoader`, `RulesUpdate`: signed remote rules with cache |
| `ErrorGuard.kt` | `GuardEvent`, `Decision`, `Suppressed`, `GuardSink`, `ErrorGuard` |
| `GuardRules.kt` | `GuardRules.parse` / `DEFAULT`, glob matcher |
| `DefaultRules.kt` | Generated by `lt-error-guard-spec/generate.js`; do not edit |
